# /octoloop — 双环一键入口

本卡是 Claude Code 的薄入口。正文对所有 agent 通用,放在仓库的
`skills/octoloop/AGENTS.md`(相对仓库根)。

**完整读取 `skills/octoloop/AGENTS.md`,按其中规程执行。** 读不到就停下
告知用户,不要凭记忆操作。

在别的项目里用 `/octoloop`:在 octoscode 仓库里执行一次
`scripts/olp-install-skill.sh`,它会装一张不含固定路径的全局薄卡。
